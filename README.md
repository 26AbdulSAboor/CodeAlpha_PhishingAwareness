# CodeAlpha_PhishingAwareness
Phishing Awareness Training project for CodeAlpha Cyber Security Internship, covering phishing attacks, social engineering, prevention techniques, real-world examples, and an awareness quiz.

## Project Overview

This project was developed as part of the **CodeAlpha Cyber Security Internship**. It provides awareness about phishing attacks and how users can identify and prevent them.

## Topics Covered

* What is Phishing?
* How Phishing Works
* Common Types of Phishing
* Identifying Phishing Emails
* Identifying Fake Websites
* Social Engineering
* Phishing Prevention
* Real-World Phishing Example
* Phishing Prevention Checklist
* Phishing Awareness Quiz

## Project File

**Phishing Awareness ppt.pptx** — Phishing Awareness Training presentation.

## Objective

The main objective is to educate users about common phishing techniques and promote safer online practices.

## Disclaimer

This project is created for educational and cybersecurity awareness purposes.
